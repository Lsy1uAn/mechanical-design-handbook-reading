三、§1.1 焊接方法怎么选（1-268～1-272）

是什么：按“要不要熔化母材”分三大类：熔化焊（母材熔化了连上）、压焊（加热到软再压上）、钎焊（母材不熔化，靠低熔点钎料粘上）。

什么时候用：选方法先看三点——板厚、批量、材料。薄板、小批量、检修多用手工电弧焊；长直焊缝、大批量、厚壁多用埋弧焊；铜、铝、钛、不锈钢多用钨极氩弧焊；薄板密封结构多用点焊、缝焊。

代表方法（表1-4-1）：气焊约3000℃，热影响区宽，只适合薄壁小件；手工电弧焊最灵活、全位置都能焊，但质量看焊工手艺；埋弧焊生产率比手弧焊高5～10倍，适合大批量长直焊缝；钨极氩弧焊气体保护充分、变形小，最适合易氧化的铜、铝、钛、不锈钢；CO₂气体保护焊成本约埋弧焊和手弧焊的40%左右，广泛用于低碳钢和低合金钢；电渣焊任何厚度不开坡口、一次焊成，但焊后必须正火；电子束、激光焊能量集中、焊缝深窄，适合精密薄壁。

热源数据（1-271）：氧-乙炔焰3473K；手工电弧焊电弧约6000K；钨极氩弧8000K；等离子弧18000～24000K。加热面积越小、功率密度越高，热影响区越窄。电弧热效率η代表值：手工电弧焊0.77～0.87，自动埋弧焊0.77～0.90，电渣焊0.83，电子束及激光束焊＞0.9。

查表方法（表1-4-2，1-272）：行=方法、列=材料，格子字母A最适用、B适用、C稍适用、D不适用；具体牌号必须查原表该格。

本节要点：先定板厚和批量，再定方法；不要只看“能不能焊”，还要看变形、成本和位置能不能施焊。

四、§1.2 金属的可焊性（1-272～1-277）

是什么：可焊性 = 在某种方法和工艺下，能不能比较容易得到优质接头。设计重要焊件，必须依据可焊性试验选母材。

碳当量公式（1-272～1-273）：国际焊接学会推荐 CE = C + Mn/6 + (Cr + Mo + V)/5 + (Ni + Cu)/15（各元素质量分数，%）。

判断：CE＜0.4%：淬硬倾向不明显，可焊性优良，不必预热；0.4%～0.6%：需适当预热、控制线能量；＞0.6%：较难焊，需较高预热温度和严格工艺。

算例（非书上原例）：C=0.20、Mn=1.20、Cr=0.30、Mo=0.10、V=0.05、Ni=0.30、Cu=0.20。
Mn/6 = 1.20/6 = 0.20；(Cr+Mo+V)/5 = 0.45/5 = 0.09；(Ni+Cu)/15 = 0.50/15 ≈ 0.033。
CE = 0.20 + 0.20 + 0.09 + 0.033 ≈ 0.523%，落在0.4%～0.6%区间 → 需适当预热、控制线能量。

常用钢材（表1-4-3，1-273）：四档——Ⅰ良好、Ⅱ一般、Ⅲ较差、Ⅳ不好。Ⅰ如低碳钢Q235、08、10、15、20；Ⅱ如Q275、30、30Mn、12CrMo、15CrMo（结构复杂或较厚时必须预热150℃以上并焊后热处理）；Ⅲ如35、40、45、30CrMo、35CrMo（焊前预热、焊后消除应力）；Ⅳ如50、55、60、45Mn2、50Cr（极易裂，预热条件下能焊，焊后必须消除应力）。沸腾钢时效敏感、冷脆倾向大，一般不宜用于动载或严寒（-20℃）重要结构；镇静钢用于动载或低温（-40℃）重要结构。

铸铁（1-273～1-274）：主要用于修补缺陷和损坏零件；要求变形小、不脆裂、不白口化、易加工、无裂纹气孔、密封性好。半热焊一般预热400℃左右并焊后保温缓冷；热焊预热500～650℃，焊接过程中不低于400℃，焊后600～650℃保温退火消除应力。

有色金属与异种金属（1-274～1-277）：表1-4-5按方法×牌号给良好/一般/较差/不好+适用厚度；表1-4-6符号：•可焊性好、○尚好但焊缝脆弱、⊕不好、×不能焊接、空白未经试焊（不锈钢与铝为×）；表1-4-7按方法分块，○=可用该方法焊。

本节要点：先算碳当量，再查表1-4-3定档；CE高不等于“不能焊”，而是“必须预热+严格工艺”。

五、§1.3 焊接材料及其选择（1-278～1-351）

是什么：焊条、焊丝、焊剂不是随便配的：焊条要和母材强度、成分匹配；焊剂要和焊丝配对；酸性、碱性焊条的用法完全不同。

药皮重量系数（表1-4-12，1-285～1-286）：K =（药皮重量 ÷ 相同部分的焊芯重量）× 100%。K=30%～50%为厚药皮焊条，K=1%～2%为薄药皮焊条。

算例：焊芯100g、药皮40g → K = 40/100 × 100% = 40%，厚药皮。

酸性 vs 碱性焊条（表1-4-17、1-4-18，1-294）：酸性焊条对水、锈气孔敏感性不大，使用前经150～200℃烘焙1h、可交直流、电流较大、可长弧、脱渣容易，但含氢量高、塑性和韧性较低；碱性（低氢型）焊条使用前经300～400℃烘焙1～2h、必须直流（加稳弧剂后才可交直流）、电流小约10%、必须短弧，但含氢量低、冲击韧度高、抗裂性好，适合重要结构。扩散氢对比：碱性1～8mL/100g，酸性17～50mL/100g。

焊剂碱度公式（IIW，1-288～1-290）：B = [CaO + MgO + BaO + Na₂O + K₂O + CaF₂ + 0.5(MnO + FeO)] ÷ [SiO₂ + 0.5(Al₂O₃ + TiO₂ + ZrO₂)]。B＜1.0酸性，1.0～1.5中性，＞1.5碱性，＞2.0高碱度。国产焊剂代表值：HJ130为0.78（酸性）、HJ131为1.40（中性）、HJ172为2.68（高碱度）。

焊条型号怎么读（表1-4-25，1-307～1-308）：E后前两位数字 = 熔敷金属抗拉强度最小值（43=≥430MPa、50=≥490MPa、55=≥550MPa、62=≥620MPa），后两位数字 = 药皮类型＋电源＋焊接位置。原例：E5515-N5PUH10——55=550MPa、15=碱性全位置直流反接、N5=化学成分分类代号、H10=扩散氢含量不大于10mL/100g。

选焊条六个因素（表1-4-20，1-296）：力学性能和化学成分、工作条件和使用性能、结构特点和受力状态、施焊条件及设备、改善工艺和保护健康、劳动生产率和经济合理性。异种钢、复合钢板按基层、过渡层、复合层三种不同性能的焊条选（过渡层选含铬比复合钢板高、塑性抗裂性较好的奥氏体不锈钢焊条）。

常用钢材选焊条举例（表1-4-23，1-297～1-301）：低碳钢大多用E43××（J42×）系列；Q235用J421、J422、J423；Q275用J426、J427、J506、J507；中碳钢、高碳钢应选用杂质含量较低且有一定脱硫能力的碱性低氢型焊条，大多数情况下需要预热和缓冷；低合金高强度钢按强度等级选，冷却速度大时可选用比母材强度低一级的焊条；不锈钢先保证耐蚀性（成分尽量接近母材），其次抗裂性和综合力学性能。

焊条性能续表（1-313～1-351，表1-4-29～1-4-31）：按型号查成分、力学性能、冲击试验温度、用途。代表行：E4303 Rm≥430MPa、ReL≥330MPa、A≥20%、冲击温度0℃；E5003 Rm 490～650MPa、ReL≥400MPa、A≥20%；E5515-N3类Rm≥550MPa、ReL≥460MPa、A≥17%、冲击温度-50℃。热强钢焊条含预热/层间温度、焊后热处理温度和保温时间（如E62XX-9C1MV预热250～300℃、焊后热处理715～745℃、保温120～300分钟）；不锈钢E308用于18-8型不锈钢，E309用于异种钢焊接，E316耐蚀性比E308好；堆焊选型主要看堆焊层硬度；碳钢药芯焊丝选型必须同时看强度、焊接位置、保护气体、电源极性（如E50XT-1：480MPa、400MPa、22%、-20℃冲击27J、位置H、F、保护气CO₂、极性DCEP）；焊剂配焊丝见表1-4-31（如HJ130配H10Mn2焊低碳钢及16Mn等）。

本节要点：型号不是装饰：前两位是强度，后两位是药皮+电源+位置；碱性焊条不烘焙、不短弧，等于白用了低氢。

六、§1.4 焊缝（1-352～1-391）

方法代号（表1-4-32，1-352，GB/T 5185—2005）：图纸上写阿拉伯数字代号，标在指引线尾部。常用：111=焊条电弧焊；121=单丝埋弧焊；131=MIG；135=MAG；136=药芯焊丝非惰性气体保护焊；141=TIG；15=等离子弧焊；21=点焊；24=闪光焊；51=电子束焊；52=激光焊；311=氧-乙炔焊。

焊缝符号怎么读（表1-4-33～1-4-38，1-353～1-359，GB/T 324—2008）：基本符号长得像坡口截面（I形、V形、U形、J形、卷边、角焊缝三角形、点焊缝圆圈等）；组合符号是两个基本符号上下拼起来（如双面V形=X形、K形）。关键规则：实线侧 = 箭头指的那一侧，虚线侧 = 背面那一侧；双面焊缝两边都画。辅助符号：平面（—）焊缝表面齐平、凸面（弧线向上）凸起、凹面（弧线向下）凹进；补充符号：垫板（方框）、三面焊缝、周围焊缝（圆圈）、现场（小旗）、尾部（可写方法代号、质量等级等）。

尺寸符号（表1-4-39，1-360）：δ=工作厚度；α=坡口角度；β=坡口面角度；b=根部间隙；c=钝边；R=根部半径；H=坡口深度；h=余高；K=焊脚尺寸；S=焊缝有效厚度；d=点焊、塞焊的孔/点直径；e=焊缝间距；l=焊缝长度；n=焊缝段数；N=相同焊缝数量。

读图算例：交错断续角焊缝：焊脚尺寸5mm、间距30mm、段数35、每段长50mm → 总焊缝长度 = 35 × 50 = 1750mm（e=30是间距，l=50是每段长，不要把30当成段长）。

坡口怎么查（表1-4-42、1-4-43，1-365～1-375；续表1-376～1-386）：薄板不开坡口（I形）直接对上焊，中厚板开V形一面焊，厚板开双面V（X形）、U形、双U形或K形两面焊。代表行：卷边坡口t≤2；I形坡口t≤4时b≈t；V形坡口t在3～10时α在10°～60°之间、b≤4、c≤2；U形坡口t＞12时β在8°～12°之间、b≤4、R在6～9之间；双面V（X形）t＞10时α≈60°、b在1～3之间、c≤2、h≈t/2（对称）。双V对称坡口公式：h₁ = h₂ = (t − c)/2。

算例：t=20mm、c=2mm → h₁ = h₂ = (20 − 2)/2 = 9mm。
双U形焊缝t≥50时h = 0.5(t − c)；t=50、c=6时 h = 0.5 × (50 − 6) = 22mm。

复合钢坡口（表1-4-44，1-378～1-381，GB/T 985.4—2008）：先分单面还是双面，再按工件厚度t1分≤18/＞18两档；另有一列复合层去除宽度e。代表行：带衬垫的V形对接焊缝t1≤18时α 50°～70°、β 5°～15°、b 3～5、c≤2、e≥4，埋弧焊时e至少8mm；双V形焊缝t1＞18时α 50°～70°、b 3～5、c≤2、h=(1/3)t1−1；t1=30时h=30/3−1=9mm。

铝及铝合金坡口（表1-4-45，1-382～1-386，GB/T 985.3—2008）：代表行：卷边焊缝t≤2，方法141；I形焊缝t≤4时b≤2，方法141；V形焊缝3≤t≤5时α≥50°、b≤3、c≤2，方法141/131；带衬垫的V形焊缝3≤t≤20时α 60°～90°、b≤4、c≤2，方法131；双面V形焊缝t＞15时141法α≥70°、131法α≥60°、c≤2、b≤3。141=TIG焊；131的全称在本章切片内未解码，未核对。

不同厚度钢板对接（1-387，表1-4-46）：薄板厚度δ1≥2～5时允许差1；＞5～9时允许差2；＞9～12时允许差3；＞12时允许差4（mm）。差超过了，就要在厚板上削薄一面或两面，削薄长度L≥3(δ−δ1)。

算例：δ=20、δ1=12，差=8＞4，必须削薄；L ≥ 3 × (20 − 12) = 24mm。

铜、铝坡口参数表（表1-4-47、1-4-48，1-387～1-388）：标题都带“（参数）”，即参考值、不是强制尺寸。代表行：铜氧-乙炔气焊板厚5～10时间隙1～3、钝边1.5～3、角度60°～80°；铜钨极手工氩弧焊板厚6时间隙0～1.5、钝边1.5、角度70°～80°。

焊缝强度计算（1-388～1-389，图1-4-3、表1-4-49）：符号σ=正应力、τ=剪应力、δ=板厚（对接时）、l=焊缝长度、a=角焊缝计算厚度，角焊缝一般取a=0.7K。基本公式代表行：对接接头拉σ=P/(δ·l)≤σ′lp，压σ=P/(δ·l)≤σ′ap；T字/十字接头角焊缝拉或压τ=P/(2al)≤τ′p（两条焊缝，所以分母有2）；T字接头弯曲一例τ=M/[l·a(δ+a)]≤τ′p；搭接接头拉或压τ=P/(2al)≤τ′p，取a=0.7K；未焊透的焊缝计算厚度取实际值，许用应力为τ′p。

算例（非书上原例）：P=100kN=100000N、δ=10mm、l=100mm → σ = 100000/(10×100) = 100MPa；对照表1-4-54，Q235第1组对接抗拉许用167MPa，100 ≤ 167，满足。

八、§1.6 钎焊（1-395～1-407）

是什么：钎焊是用比母材熔点低的金属作钎料，把焊件和钎料加热到高于钎料熔点、低于母材熔点的温度，靠液态钎料润湿母材、填充接头间隙并与母材相互扩散，把零件连起来的方法。

优点：加热温度较低，焊件组织和力学性能变化不大，变形较小，接头平整光滑，工艺简单，生产率高。缺点：一般情况下接头强度较低，必须用搭接达到与母材等强度；接头连接面间要保证一定的间隙；残余钎剂有腐蚀作用，所以对装配及钎焊后的清理要求较严。

分类：按钎料熔化温度和接头强度不同，钎料分为硬钎料（熔点在450℃以上）、软钎料（熔点在450℃以下）。

方法比较（表1-4-65，1-395～1-396）：火焰钎焊设备简单、价格低、热源可移动，但零件易氧化、局部加热工件易变形；空气炉中钎焊加热均匀、变形小、生产效率高；保护气氛炉中钎焊温度可正确控制、均匀加热、变形小、可机械化、适于大量生产；真空中钎焊可不加钎剂、表面光洁、接头抗腐蚀性好、可钎焊难钎焊的金属及陶瓷；感应钎焊加热速度快、成本低；盐浴钎焊加热均匀迅速、温度容易控制；浸渍钎焊迅速均匀加热、精确控制温度；扩散钎焊、接触反应钎焊接头质量高、易实现精密连接；烙铁钎焊设备简单、操作方便灵活，只适用于易熔钎料；波峰钎焊生产效率高，用于印刷电路板。

选材原则（表1-4-66，1-395～1-397）：钎料与母材匹配（熔点适当、润湿性和填缝能力好、避免脆性金属间化合物、晶间渗入、母材过分溶解、热膨胀系数失配）；钎料与方法匹配（电阻钎焊要求钎料电阻率比母材大一些，炉中钎焊要求易挥发元素含量少，真空钎焊要求不含蒸气压高的合金元素，火焰钎焊时钎料与母材熔点差要大）；满足使用要求（导电性、导热性、工作温度、强度、塑性、密封性、防氧化性、抗腐蚀性等，只需着重考虑最主要的使用要求）；结构要求（结构复杂时把钎料预先加工成环形、箔片、垫片、粉末等并预先放在间隙中或附近）；生产成本。钎剂选择：先考虑母材和钎料种类（锡铅钎料焊铜用活性较小的松香钎剂，焊铜用活性较强的氯化锌水溶液，焊不锈钢用活性很强的氯化锌盐酸溶液，黄铜钎料焊普通铜及铜合金用脱水硼砂，焊铝及铝合金必须用铝钎焊专用钎剂）；钎剂与方法（电阻钎焊要有一定导电性，浸渍钎焊要去除水分，感应钎焊反应快、活性要大，炉中钎焊活性可小些、热稳定性要好）；钎剂与温度（钎剂熔化温度要与钎焊温度相适应，其熔点低于钎料熔点，沸点应比钎焊温度高，最低活性温度不能比钎料熔化温度低得太多）。

钎料选择（表1-4-67，1-397～1-398）：查法是行=接合金属、列=钎接金属，或下半按钎焊方法查。代表行：铝及铝合金与铝用Al、Zn；镍及镍合金与碳钢用Cu、Ag、Cu-Zn、Cr-Ni；碳钢与碳钢用Cu、Ag、Pb、Sn、Cu-Zn、Cr-Ni；不锈钢与不锈钢用Cu、Ag、Cu-Zn、Cr-Ni；铜及铜合金与铜用Ag、Cu-P、Cu-Zn、Pb-Sn。铝与镍、碳钢、不锈钢、铸铁、铜、高碳钢、耐热钢等组合在表中标“不推荐”。

九、§1.7 塑料焊接（1-408～1-409）

是什么：不是所有塑料都能焊，热塑性塑料才能焊；方法分电加热、火加热（热空气、热惰性气体、热混合气体）、机械加热（摩擦、热工具）。

可焊性（表1-4-80，1-408）：代表行：聚乙烯（板材、薄膜）接触加热好、热空气加热好、热惰性气体加热好、热工具加热好，高频电流加热标“—”；硬聚氯乙烯塑料（板材、薄膜）接触、高频、热空气、热惰性气体、摩擦、热工具都标好；聚四氟乙烯一类难焊材料在多数方法下标“—”或“一般”，不要想当然选热焊。注：高频电流焊接广泛用于塑料薄膜（总厚度小于2mm）的焊接。

十、§1.8 焊接结构设计注意事项（1-409～1-415，表1-4-83）

总目标（4条）：在满足设计功能要求下，焊接工作量能减至最少；焊接件可不再需要或只需要少量的机械加工；变形和应力能减至最少；为焊工创造良好的劳动条件。

一般注意事项：考虑最有效的焊接位置，以最小的焊接量达到最大的效果；考虑焊接时操作方便，一般情况下要保证焊接作业的最小间隙与操作时焊条的适当角度；避免将焊缝设计在应力容易集中的地方，特别是重要部件或承受反复载荷的焊接件；合理布置构件的相互位置，以保证焊接件的刚性；在某些特别重要的焊接件中，焊接厚度不同的钢板时必须使两者中心线一致，以避免产生弯曲力矩；受变应力的焊缝，焊缝不宜凸出，宜平缓，背面补焊，最好将焊缝表面切平，避免用搭接形式，要用时可用长底的填角焊缝；在承受弯曲载荷处，应尽可能避免横向焊缝；焊缝的根部要避免处于受拉应力的状态；焊接加固件或必须退火的封闭箱体时，应钻通气孔（图示通气孔φ5–10mm），或将焊缝一段断开，避免变形；盖板与侧板焊接时，应按板的厚度选择不同的角接接头；直接传递负载的焊接件，采用整体嵌接为好；薄板焊接时，为避免拱起现象，应考虑开孔焊接；不允许液体从螺孔或其他地方泄出的焊件，在强度允许情况下，应加内部密封焊缝；在角形连接中，应避免外开口的焊缝，防止生锈，在要求密封和承受动载荷时，应在内部增加焊缝；小构件避免内部焊接，在可能的情况下，采用槽焊，δ＞12mm采用单边V形或V形焊缝而不用角焊缝；箱形焊接结构应该用带边缘的钢板或型钢拼焊；缘、辐、毂之类零件组焊时，应选用适当的间隙（机械加工件0.2–0.3mm，毛坯和气割件1–2mm）；剖分面尽可能不要被焊缝断开；焊接由扁钢制造的轮缘时，应将焊缝配置在轮齿之间，焊接前轮毂、轮缘都不要加工；毛坯上与其他件连接的部分离开焊缝至少3mm；避免焊缝过分集中，以防止裂纹、减少变形，焊缝间应保持足够的距离。

焊接操作最小空间和焊条角度：δ₁=δ₂时α=45°；δ₁＞δ₂时α＜45°；δ₁＜δ₂时α＞45°。A为使用厚涂药焊条时，B为使用薄涂药焊条时；a平焊、b立焊、c仰焊；图的具体角度分区未核对细节，以原图为准。

调节焊接应力：在残余应力为拉应力的区域内，应避免几何不连续性；采用刚性较小的接头型式，如用翻边连接代替插入式管连接，降低焊缝的拘束度；采用收缩切口来减少收缩应力。

预防焊接变形：焊接端部产生锐角的地方，应尽量使角度变钝，薄板筋的锐角必须去掉；选用合理的焊缝尺寸和型式，在保证功能要求下尺寸尽量小，对仅连接作用、用受力不大、按计算很小的角焊缝，按板厚选取工艺上可能的最小尺寸，采用X形坡口可减少对接接头的角变形，在薄板结构中采用接触点焊代替熔化焊可以减少变形和焊后校正工作，采用断续焊减少板变形、但在动载荷作用下增加应力集中的影响；合理地选择肋板的形状和布置（用槽钢加固轴承座，比用辐射肋板更好）；焊缝应交错布置，特别是厚截面时必须避免交叉焊缝；合理安排缝位置，焊缝应相对构件中性轴或靠近中性轴，以减少收缩力矩或弯曲变形；尽量减少焊缝数量，在可能情况下用冲压结构代替肋板结构；采用接触点焊，蒙皮采用接触点焊代替熔化焊可以减少变形。

防止层状撕裂：层状撕裂随着材料中夹杂物（硫化物、硅酸盐、氧化物）的数量、平行于表面夹杂物面积的增大以及密集程度的增加而增加，尤其是硫的含量影响更甚，选材时应特别注意；增大焊缝与板面的接触面积；选择适宜的坡口角度，减少空腔体积；改变焊接顺序（对称焊采用对称焊接顺序）；加中间块焊接，代替十字交叉件结构；在承载方向上，加焊变形能力大的焊接接头材料，增加缓冲层，扩大连接面；预热是减少层状撕裂的措施之一，目的是降低冷却速度，使收缩范围增大。

角焊缝的计算厚度（1-413，重要数字）：角焊缝在较小的负载下，不必计算强度，可按经验确定下凹焊缝的高度a，即按连接钢板中较薄的板厚δ计。双面角焊缝a≥0.3δ；单面角焊缝a≥0.6δ。考虑经济性，a不应超过12mm；当需要a＞12mm时，则应选择其他形式焊缝。

算例：较薄板δ=20mm时，双面角焊缝a≥0.3×20=6mm；单面角焊缝a≥0.6×20=12mm，正好到经济上限；若算出需要15mm，就不要硬做大角焊缝，改选其他焊缝形式。

经济性：提高材料利用率；合理选择焊缝型式（同一结构中尽可能选用厚度相同的钢板；V形焊缝准备成本低但焊接空间大、焊接成本提高；X形焊缝准备成本高但焊接空间较小；角焊缝中双面角焊缝所需熔接金属比单面角焊缝少、并能承受较高负载、变形也较小，应优先采用，但在一面难以施焊或处于强迫位置时采用单面角焊缝比较经济）；考虑合理的焊接位置，尽可能选择平焊。焊接位置与时间比：平焊1；横焊（角焊缝）1.3；横焊（对接焊缝）1.8；立焊2.2；仰焊2.5。

算例：平焊要10小时，同样活仰焊大约10×2.5=25小时，所以能翻成平焊就翻成平焊。在一般情况下，不需要过高的定心要求；不要把焊缝布置在加工面上；不用或少用坡口，手工电弧焊可以不用坡口的最大板厚，单边焊接为4mm，双边焊接为6mm；尽可能采用连续的细长焊缝而不用断续的短粗焊缝。

考虑焊接方法的不同特点（1-414～1-415）：埋弧自动焊——同一工件上的焊接接头应采用同一型式，而且以采用直线焊缝为好；焊缝位置需使焊接设备的调整次数和工件的翻转次数为最少；便于保存熔剂；使自动焊机能沿焊缝自由移动。接触对焊——对接两截面面积大小应相等，或者圆杆、管尺寸偏差≤15%，方杆料边长尺寸偏差≤10%；对接实心棒料a代表行：棒料直径d=6、10、14、18、22、28、36、45、55mm时，手工接触焊a=6、8、8、10、12、14、18、22、24mm，自动接触焊a=6、8、12、16、18、22、28、34、40mm，加压气焊a=2、3、4、5、7、8、11、14、17mm；薄壁管件对焊时被焊管外径d与管壁厚δ应保持右表关系，代表行：d=12→δ=0.5；38→1.5；75→2.5；150→4.0；375→8.0；500→12.5mm。接触滚焊（1-415）：必须保证接合边的最小长度a；代表行：一块板的厚度0.25–0.5mm→a=10mm；0.75–1mm→12mm；1.5mm→15mm；2mm→18mm；3mm→20mm。电渣焊（1-415）：禁用不便于电渣焊的对接截面，最便于焊接的是长方形和环形截面；焊缝上端应保留焊机退出的空间；避免焊缝中断。

本节要点：能平焊就别仰焊；能双面角焊缝就别单面大焊脚；焊缝别扎堆、别放在应力集中处。

十一、§2 铆接（1-415～1-425）

2.1 铆接设计注意事项（1-415～1-416，11条）

设铆钉直径为d，铆接总厚度为被铆的几层板加起来的厚度。

  1. 尽量要使铆钉的中心线与构件的断面重心线重合——受力不偏心，不会一边受拉一边受压。
  2. 铆接厚度一般规定不大于5d；使用大头橄榄形铆钉时，其总厚度可达直径的7倍。算例：d=10mm时，一般总厚≤5×10=50mm；大头橄榄形铆钉可到7×10=70mm。
  3. 在同一结构上铆钉种类不宜太多，一般有两种已够使用。
  4. 冲孔铆接承载力比钻孔约低20%，因此冲孔的方法只可用于不受力构件。算例：钻孔能承100，则冲孔大约只按100×(1−20%)=80估算。
  5. 冷铆一般只用于直径小于8mm、受力不大、不很重要的地方。
  6. 板厚大于4mm时才能进行敛边；板厚小于4mm而要求有很高的密封性时，可以把涂以铅丹的亚麻布放在钢板之间以获得密封性。
  7. 工地制成的铆钉，其许用应力应降低。
  8. 尽量避免焊铆同时使用。
  9. 尽量减少在同一截面上的钉孔数，将铆钉交错排列（表1-4-84中的a）。
  10. 多层板铆合时，需将各层板的接口错开（表1-4-84中的b）。
  11. 在传力铆接中，排在力的作用方向的铆钉不宜超过6个，但不应少于2个（表1-4-84中的c）。

十三、综合例题：一个Q235钢支架的焊接接头，从头做到尾

任务：做一个Q235钢支架。立板厚20mm、底板厚12mm，用双面角焊缝连起来；另有一条对接焊缝，板厚10mm、焊缝长100mm、受拉力100kN；支架总长1500mm。按本章一步步过：

第1步：能不能焊（§1.2）。Q235是低碳钢，表1-4-3属Ⅰ良好档，一般不预热。但如果环境温度低于0℃或者厚度较大，仍要按工艺要求预热并焊后缓冷（§3第6条）。

第2步：选方法（§1.1）。单件、小批量、位置不固定 → 手工电弧焊（111）；如果改成大批量长直焊缝，改埋弧焊（121）。

第3步：选焊条（§1.3）。Q235用J421、J422、J423（E43××系列）；重要结构用碱性低氢型，记得300～400℃烘焙1～2h、短弧、直流反接。

第4步：定角焊缝尺寸（§1.8）。较薄板δ=20mm，双面角焊缝a≥0.3×20=6mm；如果只做单面，a≥0.6×20=12mm，正好到经济上限12mm。结论：做双面，a取6mm以上。

第5步：算对接焊缝强度（§1.4）。σ = P/(δ·l) = 100000/(10×100) = 100MPa；Q235第1组对接抗拉许用167MPa，100 ≤ 167，满足。如果这条焊缝是动载，还要乘表1-4-56的折减系数，不能直接用167。

第6步：不同厚度对接（§1.4，表1-4-46）。如果立板20mm要和底板12mm对接，差=8mm，大于允许的4mm，必须在厚板上削薄，削薄长度L≥3×(20−12)=24mm。

第7步：公差（§1.5）。支架总长1500mm，公称尺寸＞1000～2000，一般B级线性尺寸公差±4mm；如果要求高精度，要在图样技术要求里注明等级，不能默认。

第8步：出图技术条件（§3）。图样上标注焊缝符号（GB/T 324—2008）、探伤标准和级别、是否消除应力、有预热要求要注明预热温度；涂装前按JB/T 5000.12除锈。

如果改成铆接（§2）：选d=10mm铆钉，总厚一般≤50mm，大头橄榄形铆钉可到70mm；同一截面钉孔要交错排，沿力方向一排2～6个；冲孔只用于不受力构件（承载力约低20%）。

如果再加一个铜钎焊接头（§1.6）：铜+铜用Ag、Cu-P、Cu-Zn、Pb-Sn钎料；接头间隙按表1-4-70/1-4-71取0.05～0.20mm级，例如铜+Cu-P取0.04～0.20mm；间隙太大填不满、太小流不进。

十四、错题本：最容易错的6个地方

错法对法
焊缝符号画在实线侧，就以为焊缝在背面。实线侧 = 箭头指的那一侧，虚线侧 = 背面那一侧。画反了，焊缝就焊到另一面去了。
CE=0.52%还不预热，觉得“低碳钢都能焊”。0.4%～0.6%区间要适当预热、控制线能量；＞0.6%要较高预热+严格工艺。
碱性焊条不烘焙、长弧焊接，觉得“焊条都一样”。碱性焊条用前300～400℃烘焙1～2h、必须短弧、一般直流反接；不烘焙等于白用了低氢。
单面角焊缝焊脚做到15mm，觉得“越大越结实”。经济上限是12mm；需要a＞12mm时改选其他焊缝形式，不要硬做大焊脚。
钎焊间隙留1mm，觉得“留大点好填”。钎焊间隙以0.05～0.20mm级为常见；太大会填不满、强度低，太小则钎料流不进去。
铆钉在同一截面排成一排，觉得“排整齐好看”。同一截面钉孔要交错排，多层板接口要错开，沿力方向一排2～6个。

十五、在 SolidWorks 里怎么对照

焊接、铆接、钎焊本身不是SolidWorks的建模命令，书里的规则在SolidWorks里是这样对照的：

  • 焊缝符号、坡口：工程图里按GB/T 324—2008画焊缝符号（实线=箭头侧）；三维模型里坡口要按表1-4-42/1-4-43的α、b、c、h建出来，不能只画两块板贴在一起就当焊好了。
  • 角焊缝尺寸：模型里的焊脚K和计算厚度a=0.7K要对应；双面a≥0.3δ、单面a≥0.6δ、a≤12mm的经济上限，建模和出图时都要核对。
  • 板材弯曲、展开：表1-4-89的最小弯曲半径和展开公式A=π(r+Kδ)·α/180°，和钣金展开的思路一致（中性层弧长），但K值查本章表，不要直接套钣金默认K。
  • 铆钉孔、规线：表1-4-85～1-4-88的规线a′、D就是孔位尺寸，建模时按表打孔、按交错排列布孔，不要凭感觉排一排。
  • 没有直接对照的：碳当量、可焊性、预热温度、焊条烘焙、钎焊间隙、探伤级别，这些是工艺和检验要求，SolidWorks模型里没有对应命令，要写在图样技术要求里。

十六、自测题（带详细答案）

1. 某钢C=0.20、Mn=1.20、Cr=0.30、Mo=0.10、V=0.05、Ni=0.30、Cu=0.20，算CE并判断要不要预热。
答：Mn/6=0.20；(Cr+Mo+V)/5=0.45/5=0.09；(Ni+Cu)/15=0.50/15≈0.033；CE≈0.20+0.20+0.09+0.033=0.523%。落在0.4%～0.6%区间 → 需适当预热、控制线能量。

2. 较薄板δ=20mm，双面角焊缝和单面角焊缝的a各至少多少？单面做到15mm行不行？
答：双面a≥0.3×20=6mm；单面a≥0.6×20=12mm。单面15mm不行，经济上限是12mm，需要a＞12mm时改选其他焊缝形式。

3. 对接焊缝P=100kN、δ=10mm、l=100mm，算应力，并判断Q235第1组够不够。
答：σ=100000/(10×100)=100MPa；Q235第1组对接抗拉许用167MPa，100≤167，满足（静载；动载还要乘折减系数）。

4. 20mm板和12mm板对接，差8mm怎么办？削薄长度至少多少？
答：允许差只有4mm，8mm超了，必须在厚板上削薄；L≥3×(20−12)=24mm。

5. d=10mm铆钉，一般总厚最多多少？大头橄榄形铆钉呢？沿力方向一排最多几个、最少几个？
答：一般≤5×10=50mm；大头橄榄形可到7×10=70mm。沿力方向一排不宜超过6个，不应少于2个。

6. 铜钎焊接头间隙留1mm对不对？为什么？
答：不对。钎焊间隙以0.05～0.20mm级为常见（铜+Cu-P取0.04～0.20mm）；1mm太大会填不满、强度低。
