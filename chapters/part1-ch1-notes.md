## 本章总结

这一章是全书的“工具箱”：先给常用资料表（字母、标准代号、效率、密度、
弹性常数、摩擦、热性能），再定单位和换算（SI、符号写法），再给选尺寸的
优先数系，然后是数表、数学符号、数学公式，最后是力学公式
（运动、材料力学、接触、动荷、厚壁/平板/稳定性）。
建模时最常用的是：§1的密度与效率、§2的单位换算与 1 MPa = 1 N/mm²、
§3的优先数选尺寸、§5的应力与稳定性公式；其余多为“知道去哪张表查”。

## 一、§1 常用资料和数据（1-3～1-12）

- 字母查法（1-3，表1-1-1）：汉语拼音字母 + 希腊字母正体/斜体
  （GB 3101—1993）+ 英文名/音标；注音为近似音，V只拼外来语等，
  无声母时 i 写 y、u 写 w。
- 标准代号反查（1-4，表1-1-2）：代号→标准名称，分国内/国外；
  /T 为推荐性标准，/Z 为指导性技术文件，ZB后字母分专业，台湾为CNS，
  ISO前身ISA、ANSI前身ASA/USASI。
- 传动效率 η（1-5，表1-1-3）：按类别→型式（含精度/润滑/头数）查；
  滑动丝杠 0.3～0.6，滚动丝杠 0.85～0.95，V带 0.96，滚子链 0.96，
  球轴承稀油润滑 0.99。
- 密度（1-6，表1-1-4）：材料→密度，单位 t/m³，20℃数据、部分近似；
  **质量 = 体积 × 密度**——算零件重量就用这张表。
- 松散物料（1-6～1-7，表1-1-5）：物料→密度 + 安息角（运动/静止），
  料斗/输送估算用。
- E、G、μ（1-7，表1-1-6）：材料→弹性模量E、切变模量G（GPa）、泊松比μ；
  表中空格 ≠ 0，不要当0用。
- 物理常数（1-8，表1-1-7）：名称→符号→数值→单位；
  常用 g = 9.80665 m/s²、标准大气压 101325 Pa。
- 滑动摩擦 μ（1-9，表1-1-8）：摩擦副→无润滑/有润滑 μ；
  ①静、②动，无标注者动静兼用；仅作近似参考。
- 工程塑料摩擦（1-10，表1-1-9）：下试样塑料行 × 上试样钢/塑料列，
  分 μs/μk；① = 黏滞运动。
- 轴承等摩擦（1-10，表1-1-10）：滚动轴承按径向/轴向载荷查，
  滑动轴承按摩擦状态查；滚动/轧辊轴承值为有润滑无量纲值。
- 滚动摩擦（1-11，表1-1-11）：平面滚动 M = Nμk = Fr；
  双圆柱 M = Nμk(1 + r1/r2)；辊上平台 F = (N/d)(μk + μk1)；
  μk单位cm、大约值。
- 金属热性能（1-11，表1-1-12）：熔点、热导率、比热容，后两者为20℃数据。
- 线胀系数（1-11，表1-1-13）：材料行 × 温度范围列查 αl，单位 10⁻⁶℃⁻¹。
- 液体/气体性能（1-12，表1-1-14/1-1-15）：密度（20℃）、熔点、沸点、
  热导率、比热容；气体在 101.325 kPa 下测出，cp/cv分列，
  水蒸气项为100℃测出。

## 二、§2 法定计量单位和常用单位换算（1-13～1-38）

### 2.1 法定计量单位（1-13～1-30，表1-1-16、1-1-17）

- SI词头（1-13）：k千10³、M兆10⁶、G吉10⁹、m毫10⁻³、μ微10⁻⁶、n纳10⁻⁹；
  全表 Y 10²⁴ 至 y 10⁻²⁴；10⁴称万、10⁸称亿，不与词头混淆。
- 基本量（本节表中标“基本量之一”者）：长度m（1-14）、时间s（1-14）、
  质量kg（1-16）、热力学温度K（1-20）、电流A（1-23）、发光强度cd（1-28）；
  平面角rad、立体角sr列为无量纲量（1-13）。
- 力（1-17）：N，1 N = 1 kg·m/s²；重量 W = mg；日常把质量叫“重量”是习惯，
  量仍用kg。
- 力矩/转矩（1-18）：N·m，M = r×F；弹性力学中 M表弯矩、T表扭矩。
- 压力/应力（1-18）：Pa，1 Pa = 1 N/m²；**1 MPa = 1 N/mm²**；
  表压 pₑ = p − p_amb。
- 弹性模量（1-18）：E、G、K均为Pa；应变、泊松比无量纲。
- 能与功率（1-19）：J，1 J = 1 N·m = 1 W·s；W，1 W = 1 J/s。
- 转速与重力（1-15）：转速常用 r/min，1 r/min = π/30 rad/s；
  gₙ = 9.80665 m/s²。
- 密度（1-16）：1 t/m³ = 10³ kg/m³ = 1 g/cm³。
- 摄氏温度（1-20）：t = T − 273.15（t单位℃，T单位K）。
- 符号写法（1-13、1-30，最易错）：量的符号斜体、单位符号正体
  （如质量m斜体、kg正体）；源于人名的单位首字母大写、其余小写
  （升L除外），如N、Pa；组合单位中角度用 (°)、(')、(") 形式，
  不用 °/s 而用 (°)/s；角度最好十进制细分，如17°15′写成17.25°；
  米不得称公尺，立方厘米用cm³不用cc。

### 2.2 常用单位换算（1-31～1-38，表1-1-18至1-1-36）

- 读法：矩阵表，行首1单位 × 系数 = 列首单位；只记主系数，细项查原表。
- 长度（1-31）：1 in = 0.0254 m、1 ft = 0.3048 m、1 mile = 1609.344 m、
  1 n mile = 1852 m（准确值，只用于航程）。
- 面积（1-31）：1 in² = 6.4516×10⁻⁴ m²、1 acre = 4046.86 m² = 0.404686 ha。
- 体积（1-32）：1 m³ = 1000 L、1 UK gal = 4.54609 L、1 US gal = 3.78541 L。
- 质量/转动惯量（1-32）：1 lb = 0.45359237 kg、1 lb·ft² = 0.04214 kg·m²。
- 速度（1-33）：1 km/h = 1/3.6 m/s、1 kn = 0.514444 m/s。
- 压力（1-34）：1 bar = 10⁵ Pa、1 atm = 101325 Pa、
  1 kgf/cm² = 98066.5 Pa、1 lbf/in² = 6894.76 Pa。
- 力（1-35）：1 kgf = 9.80665 N、1 lbf = 4.44822 N。
- 力矩（1-35）：1 N·m = 0.101972 kgf·m = 0.737562 lbf·ft；
  英制功用 ft·lbf 以区别于力矩 lbf·ft。
- 功/功率（1-35/1-36）：1 kW·h = 3.6 MJ、1 kcal_IT = 4186.80 J、
  米制马力 = 735.499 W、英制马力 = 745.700 W（米制马力无国际符号，PS为德国符号）。
- 硬度（1-38，表1-1-36）：只作查表，不作公式换算；注称应尽量避免换算、
  只当组织均匀时较精确、不包括低碳钢。

## 三、§3 优先数和优先数系（1-39～1-44）

- 目的（1-39）：主参数按优先数系成系列，可走上系列化、标准化；
  便于分析参数关系、减少计算量；用较少品种满足较宽范围需要，便于各专业协调。
- 定义（1-39）：公比为 ⁵√10、¹⁰√10、²⁰√10、⁴⁰√10、⁸⁰√10，
  且项值含10整数幂的几何级数常用圆整值，记作R5、R10、R20、R40、R80；
  分基本、补充、变形（派生、复合）、化整值系列。
- 公比近似值（1-41）：R5 ≈ 1.6；R10 ≈ 1.25；R20 ≈ 1.12；R40 ≈ 1.06；R80 ≈ 1.03。
- 查表法（1-39、1-41）：表1-1-38只列1～10段内项值；
  大于10 / 小于1的数用10、100…或0.1、0.01…乘基本/补充系列项值（十进延伸法）。
  表中序号N用于运算，常用值相对误差 =（常用值 − 计算值）/ 计算值 × 100%。
- 序号运算（1-41）：乘→序号相加；除→序号相减；乘方→指数 × 序号；
  开方→序号 ÷ 根指数。例：3.15 × 1.6 = 5（序号20 + 8 = 28）；
  4.25 ÷ 25 = 0.17（25 − 56 = −31）；(1.18)² = 1.4；√0.16 = 0.4。
- 派生系列（1-40）：基本系列不能满足分级要求时才用，记 Rr/p（每隔p项取一）；
  例 R5/2、R10/2、R10/3、R20/6、R40/5；公比 10^(p/r)。
- 选系列原则（1-41）：优先项数最少者，R5 > R10 > R20 > R40；
  相对差 R5 ≈ 60%、R10 ≈ 25%、R20 ≈ 12%、R40 ≈ 6%、R80 ≈ 3%；
  R80尽可能少用。派生系列优先考虑顺序：R5/2、R10/3、R10/5、R20/3、
  R20/4、R40/3、R40/5。实在不能用优先数时才用化整值（表带*号者），
  优先第一化整值系列，且尽量保持公比均匀；不全适用时只在基本参数和
  主要尺寸上用优先数；精密产品参数可直接用计算值（精确到5位数，误差 < 0.00005）。
  化整值括号内尺寸、特别是标*的1.5应尽可能不用。
- 应用示例：起重机滑轮（1-42～1-44）
  - 总原则（1-42）：主参数系列最大限度用优先数；老产品先整顿再选系列；
    零部件系列设计中选主要尺寸作自变量取优先数。
  - 取优先数的量（1-42）：钢丝绳直径 dr 取R20（10～60 mm）；滑轮公称直径D取优先数；
    槽底圆弧半径 r 取优先数（则槽形各尺寸皆为优先数）；孔径d、轮毂长度l取优先数。
    而底径 Db = D − dr、外径 Da = Db + 2H 一般不再是优先数。
  - D的定法（1-42）：D取R20；D/dr取20、25、31.5倍（倍数亦按优先数），
    称20型、25型、31.5型，按表1-1-39排表。
  - 槽底半径（1-42～1-43）：r ≥ dm/2 + √(α² + β²)，α = 绳径公差的1/4，
    β = 槽底半径公差的1/2；算得值圆整为R20优先数。
  - 轮缘宽（1-43）：A = E + 4.25√r，算得值圆整为相近R40优先数。
  - 轴承载荷（1-43）：P = 2Pa = Pb/n，n = 6故 P = Pb/3；
    例 dr = 10 mm、Pb = 60.3 kN时 P = 20.1 kN ≈ 20 kN；
    因 P ∝ dr² 且 dr为R20，故P为R20/2 = R10系列。
  - 孔径与轮毂长（1-43～1-44）：d取R20、l取R10；
    l = P/(d·Bp) ∝ dr²/d（Bp = 900 N/cm²），固定dr时 l ∝ 1/d，
    在优先数刻度d–l图中为斜率−1直线；算例 d = 100 mm时，
    dr = 10 mm → l = 22.4 mm，dr = 56 mm → l = 710 mm；
    极限范围 dmin = l/2.72、dmax = 1.80l；最后把l中非R10的值向上修正到R10。
  - 选配表（1-45页首，表1-1-40，补读）：滑轮的孔径和轮毂长度，
    行 = 钢丝绳直径dt、轴孔径d，列 = 轮毂长度l（40～400），
    表中×为适用组合；用时按dt、d查l，不要自编组合。

## 四、§4 数表与数学公式（1-45～1-99）

### 4.1 数表（1-45～1-46）

- 表1-1-41 二项式系数（1-45）：行n = 1–15，列p = 0–15，交点即 C(n,p)；
  书例 (a+b)⁸ 系数为 1, 8, 28, 56, 70, 56, 28, 8, 1。
- 表1-1-42 正多边形（1-46）：符号 n边数、C边长、R外接圆半径、
  r内切圆半径、A面积；C = 2R·sin(180°/n) = 2r·tan(180°/n)；
  R = C/[2·sin(180°/n)] = r/cos(180°/n)；
  r = (C/2)·cot(180°/n) = R·cos(180°/n)；
  A = (n/2)R²·sin(360°/n) = n·r²·tan(180°/n) = (n/4)C²·cot(180°/n)。
  表行 n = 3–12, 16, 20, 24, 32, 48, 64；知C/R/r任一，查同行其余与面积系数。
  建模用：正多边形法兰、螺母外形、均布孔节圆。
- 弓形（1-46）：r、h弓形高、c弦长、l弧长、α圆心角；
  r = (c²+4h²)/8h，c = 2√[h(2r−h)] = 2r·sin(α/2)，l = 0.01745·r·α°，
  α° = 57.296·l/r。建模用：弧段/弦高换算。

### 4.2 数学符号 GB 3102.11-1993（1-47～1-52，表1-1-43）

- 纠正：本节只有数学符号，**没有长度、面积、体积、力、应力等物理量符号**，
  不要把本节当物理量符号表用。
- 几何（1-47）：线段 AB上加横线；∠平面角；弧AB上加弧线；π圆周率；

- 关系（1-47）：= 强调为数学恒等；≠；定义为（等号上加def）；
  ≜ 对应（如地图1cm ≜ 10km）；≈、∝、: 比、≤/≥、≪/≫、∞、a∼b数值范围。
- 运算（1-47～1-48）：有小数点时乘法只用×；∑、∏；
  a^(1/n) / ⁿ√a（复杂被开方数加括号）；n!，0! = 1；

- exp/log/trig（1-48～1-49）：e = 2.7182818…；ln x = logₑx、lg x = log₁₀x、
  lb x = log₂x——**不可与 plain log x 互换**；
  sin/cos/tan（tg）/cot/sec/csc 及 sinh/cosh/tanh等，带别名；
  反三角/反双曲用 arcsin/arcsinh 形式，带主值范围，
  书中明禁 sin⁻¹x、cos⁻¹x、sinh⁻¹x 等写法（易误读为倒数）。
- 复数（1-49）：i、j，i² = j² = −1（j多用于电工）；Re、Im、|z|、arg、z*共轭。
- 矩阵（1-50）：A = (a_ij)，m行 × n列；AB要求A列数 = B行数；
  E/I单位阵、A⁻¹、Aᵀ转置、A*共轭、Aᴴ厄米共轭、det、tr、‖A‖（多种范数定义）。
- 坐标系（1-50）：直角坐标x,y,z为右手系（图1）；圆柱坐标ρ,φ,z（z=0退化为极坐标）；
  球坐标r,θ,φ（图3–5右手系）。左手系（图2，x轴指向内）只可例外使用，
  **必须明示**，否则易出符号错。
- 向量/张量（1-51）：印刷粗体a，手写 a上加箭头；x₁,x₂,x₃爱因斯坦求和
  （重复指标对1,2,3求和）；|a|模、e_a = a/|a|单位向量；点乘a·b、
  叉乘a×b（右手系分量如印刷）；∇、grad、div、rot/curl、拉普拉斯Δ、
  达朗贝尔□，c = 299792458 m/s；二阶张量T，分量T_ij，并矢a_i·b_j。
- 逻辑/集合（1-52）：∧∨¬⇒⇔∀∃；∈∉；区间[a,b]、]a,b]、[a,b[、]a,b[；
  ⊆⊂⊇⊃∪∩＼、A×B笛卡儿积；N（非负整数）、Z、Q、R、C。

### 4.3 数学公式（1-53～1-99，另含1-100页首表1-1-79续项）

  - 一元二次（1-55）：ax² + bx + c = 0（a ≠ 0），

  - 基本关系（1-63）：sin²α + cos²α = 1；
    倍角 sin 2α = 2 sin α cos α，cos 2α = 1 − 2sin²α = 2cos²α − 1。

    余弦定理 a² = b² + c² − 2bc·cos A；
    面积 S = (1/2)ab·sin C = √[p(p−a)(p−b)(p−c)]，p = (a+b+c)/2。
- 坐标变换（1-67～1-68）：平面极坐标互换 x = ρ cos θ，y = ρ sin θ，

## 五、§5 常用力学公式（1-100～1-202）

### 5.1 运动学、动力学基本公式（1-100～1-111，表1-1-80～1-1-84）

- 边界：1-100上半页是上一节几何体表续项，不属§5.1；§5.1从1-100下半页开始。
- 直线运动（1-100）：匀速 s = s₀ + vt；匀变速 s = s₀ + v₀t + ½at²
  = (v²−v₀²)/2a，v = v₀ + at；自由落体（v₀=0，a=g）：h = ½gt²，
  v = gt = √(2gh)。
- 抛射运动（1-100）：x = v₀t·cosθ，y = v₀t·sinθ − ½gt²；
  vx = v₀cosθ，vy = v₀sinθ − gt；ax = 0，ay = −g；

  （书中作 s = 2s₁，s₁ = v₀²sin2θ/2g）。
